# Lariat v6 — rebuild

Эта версия намеренно уменьшена до 12 разных игр вместо большого каталога заглушек.
Цель v6 — рабочая база и новый визуальный язык.

Игры: Крестики-нолики, Четыре в ряд, Пары, Сапёр, Погаси свет, Пятнашки,
Быстрый счёт, Найди лишнее, Угадай число, Простое число, Ним, Числовой ряд.

На главном экране есть заметная метка `v6`. Если после установки вы не видите `v6`,
значит на телефоне запущен старый APK.

В архиве также лежат PROMPT_LARIAT.md и VERIFICATION.txt.
